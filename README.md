# 📄 Mon CV en Ligne

Premier projet web réalisé pour présenter mon parcours, mes diplômes et mes compétences.

## 🛠️ Technologies
- **HTML5** : Structure sémantique du contenu.
- **CSS3** : Design et mise en page.

Réalisé dans le cadre de ma formation **Tremplin Numérique**, ce projet est le premier d'une série de réalisations web. Il m'a permis de mettre en pratique les bases du développement web après avoir suivi les cours sur **OpenClassrooms**.
